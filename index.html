راهنمای فعال‌سازی نسخه آنلاین (رایگان)
  1. به console.firebase.google.com بروید و با جیمیل وارد شوید.
  2. پروژه جدید بسازید (نام دلخواه، مثلاً solico-north).
  3. از منوی سمت چپ: Build → Realtime Database → Create Database → حالت Test mode → Enable.
  4. از تنظیمات پروژه (چرخ‌دنده) → Project settings → بخش Your apps → Web ( ) → ثبت اپ.
  5. مقدارهای config را کپی کنید و داخل فایل index.html در بخش FIREBASE_CONFIG جایگزین کنید.
  6. در Realtime Database → Rules این را بگذارید و Publish کنید:
    { "rules": { ".read": true, ".write": true } }
  7. فایل را ذخیره و دوباره باز کنید. باید «آنلاین — همگام‌سازی فعال» ببینید.
